## How to Use the New Recipes

### 🚀 **Database Seeding**
```bash
# Run the healthy foods seeder
php artisan db:seed --class=HealthyFilipinoFoodsSeeder

# Or run all seeders
php artisan db:seed
```

### 📱 **API Endpoints**
All new recipes are available through existing API endpoints:
- `GET /api/recipes` - Get all recipes (now 70 total)
- `GET /api/recipes?category=Healthy` - Get healthy recipes only
- `GET /api/recipes?is_filipino_dish=1` - Get Filipino dishes only

### 🔍 **Filtering Options**
- Filter by category: `Healthy`, `Filipino`, `Main Course`, etc.
- Filter by difficulty: `Easy`, `Medium`, `Hard`
- Filter by calories: Low-calorie, medium-calorie, high-calorie options
- Filter by meal type: Breakfast, lunch, dinner, snack
